# Support

## Questions and help

- Open a GitHub Discussion or issue at https://github.com/pinoutlabs/pinout/issues
- Search existing issues before opening a new one.

## Bug reports

Include:

1. Pinout version (`pinout --version` or package version)
2. Node version (`node --version`)
3. Minimal reproduction (code snippet or command)
4. What you expected vs. what happened
5. Relevant device context (device class, module, transport) — never secrets

## Security issues

Do not open public issues for security vulnerabilities. See
[SECURITY.md](./SECURITY.md) for responsible disclosure.

## Commercial / physical-safety concerns

Pinout software is not a certified safety system. Never rely on it as the sole
safety layer for machinery. Safety-critical deployments require independent
hardware safeguards.
